### Synthesisers and editors

| Project | Description |
| --- | --- |
| [Overtonium](https://github.com/benjamindehli/overtonium) | Additive synth laid out as a 32-channel mixer, one sine per harmonic, tuning swept from equal temperament to just. C++, VST3/AU/LV2/standalone |
| [SidStation ASID](https://github.com/benjamindehli/sidstation-asid) | The Elektron SidStation's three SID voices as three independent DAW instruments, over ASID. C++, VST3/AU/standalone |
| [microSAMPLER Editor / Librarian](https://github.com/benjamindehli/microsampler-editor-librarian) | Editor and librarian for the Korg microSAMPLER, replacing Korg's 32-bit one. Python, macOS and Linux |

### Sampled instruments

VST3, AU and standalone plugins for macOS, each with its own interface. On Windows and Linux they run as Decent Sampler libraries instead. GPL-3.0.

| Project | Sampled from |
| --- | --- |
| [MaskinTrommer](https://github.com/benjamindehli/MaskinTrommer) | Electronic drums built on analog synthesisers |
| [Midnight Wurli](https://github.com/benjamindehli/MidnightWurli) | A Wurlitzer 200A played softly, line out and contact mic |
| [EDB-Orgel](https://github.com/benjamindehli/EDB-Orgel) | Four kinds of digital synthesis behind nine drawbars |
| [SubC](https://github.com/benjamindehli/SubC) | A Dreadbox Erebus v2 triangle oscillator, saturated |
| [4-track Toy Piano](https://github.com/benjamindehli/4-track-toy-piano) | A Kalikå Leksakspiano on tape, normal and half speed |
| [Elektrisk Salmesykkel](https://github.com/benjamindehli/ElektriskSalmesykkel) | A Yamaha L-20D electric harmonium |
| [StyloPoly](https://github.com/benjamindehli/StyloPoly) | A Dubreq Stylophone S-1, turned polyphonic |
| [Strykebrett](https://github.com/benjamindehli/Strykebrett) | A Hohner / Logan String Melody II |
| [4-track Glockenspiel](https://github.com/benjamindehli/4-track-glockenspiel) | A glockenspiel on tape, half speed an octave down |
| [4-track Music Box](https://github.com/benjamindehli/4-track-music-box) | A music box on tape, normal and half speed |
| [Voltage Controlled Cassette Organ](https://github.com/benjamindehli/VoltageControlledCassetteOrgan) | A Korg CX-3 on tape, wow and flutter included |
| [Omni-84](https://github.com/benjamindehli/Omni-84) | Every sound of a Suzuki Omnichord OM-84. Free |
| [Lo-fi Tape Piano](https://github.com/benjamindehli/lo-fi-tape-piano) | A Louis Zwicki Pianette through three mics onto tape |
